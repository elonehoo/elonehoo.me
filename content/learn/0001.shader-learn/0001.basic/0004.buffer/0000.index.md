RGBA 小数 → 深度 / 混合 → 颜色缓冲 → canvas

`gl_FragColor` 是输出槽：赋值不会结束 main，执行到 } 时留下的值才写进缓冲区。

> 片元输出四个 0～1 小数；写进颜色缓冲时变成 0～255 的字节。最后一次写入才算数。

## 试一试

- 把 R 调到 1，看字节变成 255
- 把 A 调到 0.5：第四个字节变成 128，背景从后面透出来
- 打开「继续改写颜色」，第二次写入覆盖了第一次
