:::讲解

canvas 是网页里的一块画布。 JavaScript 把数据和 shader 交给 WebGL,GPU 为每个像素算出颜色，写回这块画布。

右边的颜色来自片元 shader 里的三个数。划线的数字可以直接改，也可以按住左右拖。`gl_FragColor` 把这个颜色写进 canvas。

## 试一试

- 把三个数改成 `1.0, 0.0, 0.0`，画布变成纯红
- 三个数相等时，是一种灰色
